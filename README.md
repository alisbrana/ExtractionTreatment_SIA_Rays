# Effects of lipid–urea extraction protocols on stable isotope values in two Mediterranean myliobatid
## Abstract
Stable isotope analysis is widely used to investigate elasmobranch trophic ecology, but processes like lipid and
urea extraction can alter isotopic values, limiting comparisons among studies. We evaluated two extraction
protocols in two vulnerable batoid species, the eagle ray (*Myliobatis aquila*) and bull ray (*Aetomylaeus
bovinus*), which are rarely available for study. The extraction method significantly affected delta N in *M. aquila*,
but not in *A. bovinus*, whereas delta C was not significantly affected in either species. These findings highlight
the importance of considering extraction procedures when interpreting stable isotope data in batoids.
